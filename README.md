# 🌸 ScentBook

Application web pour explorer un catalogue de parfums (notes de tête, de cœur et de fond, accords), gérer sa collection et sa wishlist et obtenir des recommandations, composée d'un front, d'une API back et d'une base de données PostgreSQL, conteneurisée avec Docker et déployée sur Kubernetes.

> Projet ESILV M1 – Conteneurisation & Orchestration · Mehdi Bencheikh
